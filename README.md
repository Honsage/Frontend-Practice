# Frontend Practice

This repository contains labs and projects that were written to practice frontend development. Projects with `YP_` prefix were developed during study on the Yandex.Practicum course "Frontend Development".

## Yandex.Practicum Projects

### YP1

*Study lab* around HTML tags and page markup.

### YP2

*Study lab* to practice BEM (block-element-modifier) methodology in CSS.

### YP3

*Study lab* to practice CSS layout reproduction from Figma design.

### YP4

*Study lab* around binding JavaScript to page.

### YP5

*Study project* to practice forms and data validation.

### Mesto

*Study project* to practice popups and code components in JavaScript.

### WebLarek

*Study project* to practice MVP architecture in raw TypeScript frontend.

### BlogCustomizer

*Study project* to practice React and hooks in SPA.

### StellarBurger

*Study project* to practice Redux stores and Router in React SPA. Also practice Jest and Cypress for testing.

## Other sections

### Routing

*Study project* to practice Vite project, React Router, dynamic parameterized routes, and component composition.
